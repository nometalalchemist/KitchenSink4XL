## Fix wave 4 additions (metamorphic + geriatric rounds, 2026-09-05)

- **Geriatric L-2** — the trailing-styled-empties shape (QuickBooks/ERP
  exports) taxes every model-loading read 5-7s (openpyxl parses ~480k
  styled empty cells; linear and honest, not a hang). Options: document
  get_workbook_metadata as the cheap orient call in the read docstrings, or
  ship a style-bloat trim tool (audit_styles already reports the bloat).
- **Metamorphic F1 residual** — full-precision (17-significant-digit)
  doubles still cannot be WRITTEN through the file tier; the refusal now
  names the cells and the cause (storage limit, round or use COM), but a
  raw-surgery write path could store the exact text and lift the limit.
- **Metamorphic F2 residuals** — untouched-number preservation deliberately
  keeps hands off cells an op rewrites wholesale: values moved by sort /
  copy_range / move_range still land at 16 digits (they are WRITTEN cells;
  restoring would corrupt the op's own result), and a sheet touched by a
  MOVE edit skips preservation entirely. Lifting these needs value
  provenance through the op, queued as future work.
- **F2 COM ground-truth note (2026-09-05)** — this Excel build's comparison
  optimization makes a direct =IF(A1=0.3,...) read EQUAL for the full
  17-digit double AND its snap (probe-proven), so the metamorphic report's
  IF-flip repro does not reproduce as literally stated; MATCH exact-match
  and non-final subtractions DO distinguish the 1 ulp (verified), which is
  exactly the reconciliation/lookup risk class the report named.
